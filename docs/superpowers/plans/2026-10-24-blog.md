# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an English blog on rihardszeila.com (`/blog`, `/blog/<slug>`) that replaces the six standalone kit pages as the destination for LinkedIn lead-magnet posts.

**Architecture:**
- Articles are Markdown files with flat front matter. The app loads them with `import.meta.glob` and renders them with `marked`.
- A pure, dependency-free core module (`src/lib/blog-core.ts`) parses articles and rewrites HTML head tags. Three things share it: the app, a Vite plugin that writes one preview HTML file per article inside `vite build`, and a Node self-check.
- The old `public/kits/*.html` files become forwarding stubs.

**Tech Stack:** Vite 5, React 18, TypeScript, Tailwind 3 with `@tailwindcss/typography` (already installed, not yet enabled), `marked` (the one new dependency), Node 26 for the `.ts` self-checks (it runs TypeScript natively).

**Spec:** `docs/superpowers/specs/2026-10-24-blog-design.md`

## Global Constraints

- Article body on warm white `#fbfaf7`. Links on white use about `#0277a8`. Bright `#03c3f8` is never small text on white.
- The navy title block and the front page use the site's own tokens (`bg-background`, `.eyebrow`, `.heading-elegant`, `.body-clean`, `.lift`). No `shadow-[0_0_...rgba(3,195,248,...)]` glows.
- Nothing is hidden until an animation runs. No `useReveal`, no `opacity-0` gating, and no `animate-*` with fill `both` on blog content.
- Never name the print-on-demand shop, its niche, theme or franchise. Strip:
  - portraits and group portraits
  - canvas
  - glasses detection
  - the commissioning certificate
  - theme collections
  - the "explicit franchise terms" line

  The shop's real names must never be written into this repo.
- Slugs, fixed once published:
  - `marketing-department-on-claude-and-n8n`
  - `meta-ads-seven-rules`
  - `carousel-generator`
  - `ecommerce-business-built-with-claude`
  - `cheap-leads-post-mortem`
  - `ai-review-layer`
- No `/lv/blog`. The Latvian menu and the LV flag on blog pages go to `https://marketingaskola.lv/blogs/`.
- `src/components/ui/` is stock shadcn. Do not edit it.
- Verify pages with `node scripts/shoot.mjs`, never with the Claude Code browser pane.
- Nothing is pushed to `main` until Rihards has seen the six articles and said go.

## Review Focus

1. **A phone at 375px opening an article with a wide table or long code line:** the table or code scrolls inside its own box, and the page itself never scrolls sideways. Task 3 step 6 pins this with screenshots.
2. **A deep link opened cold from a LinkedIn DM, as `/blog/<slug>` and `/blog/<slug>/`:** both render the article, and the served HTML carries that article's title. Task 4 step 4 pins this.
3. **An unknown slug (`/blog/nope`):** renders the site's NotFound page and doesn't crash. Task 2 step 7 pins this.
4. **An old kit link, including one with a query string (`/kits/ads.html?v=2`):** lands on the article. Task 4 step 5 pins this.
5. **A Latvian visitor:** the `/lv` menu shows "Blogs", which leaves for marketingaskola.lv. On `/blog`, the LV flag goes there too and never to a NotFound `/lv/blog`. Task 2 step 7 pins this.

### Task 1: Blog core (parse articles, rewrite preview tags)

**Files:**
- Create: `src/lib/blog-core.ts` (no imports, only erasable TypeScript, so Node can run it)
- Test: `src/lib/blog-core.test.ts`

**Interfaces:**
- Produces:
  - `type Article = { slug: string; title: string; description: string; date: string; topic: string; drawing: string; order: number; body: string; readingMinutes: number }`
  - `parseArticle(slug: string, raw: string): Article`. Front matter is between the first two `---` lines, one `key: value` per line, with the value trimmed. `order` defaults to 99. `readingMinutes = max(1, ceil(words / 220))`, counted on the body with HTML tags removed. It throws `Error("<slug>: missing <field>")` when title, description, date, topic or drawing is missing.
  - `sortArticles(list: Article[]): Article[]` sorts newest date first, then `order` ascending. It does not mutate its input.
  - `previewHtml(base: string, m: { title: string; description: string; url: string; image: string }): string` returns `base` with these set:
    - `<title>`, `meta[name=description]`, `link[rel=canonical]`
    - `og:url`, `og:title`, `og:description`, `og:image`, with `og:image:width` 1200 and `og:image:height` 630
    - `og:type` = `article`
    - `twitter:url`, `twitter:title`, `twitter:description`, `twitter:image`
    - the `hreflang="lv"` alternate removed, and the `en` and `x-default` alternates pointed at `m.url`

    It escapes `&`, `<`, `>` and `"` in all inserted values.

- [ ] **Step 1: Write the failing self-check** `src/lib/blog-core.test.ts`, using `node:assert/strict` in the style of `src/hooks/use-count-up.test.mjs`:
  - `parseArticle("x", "---\ntitle: T\ndescription: D\ndate: 2026-10-26\ntopic: Ads\ndrawing: bars\n---\n" + "w ".repeat(440))` gives `title === "T"`, `order === 99` and `readingMinutes === 2`. The same with `"w ".repeat(441)` gives 3.
  - A file missing `description` throws `/x: missing description/`.
  - `sortArticles` on dates `2026-10-26/order 2`, `2026-10-26/order 1` and `2026-11-01` gives `[2026-11-01, order 1, order 2]`, and the input array is unchanged.
  - `previewHtml` on the real `index.html` (read with `fs`), given title `A & "B"`:
    - contains `<title>A &amp; &quot;B&quot;</title>` and `property="og:type" content="article"`
    - contains `property="og:image:width" content="1200"`
    - does not contain `hreflang="lv"`
    - does not contain `Paid Growth Consultant`
- [ ] **Step 2:** Run `node src/lib/blog-core.test.ts`. Expected: it fails with a module-not-found error.
- [ ] **Step 3:** Implement the three functions in `src/lib/blog-core.ts`. Use regex replacement on the known tag shapes in `index.html`. Don't use a DOM parser, because the module must stay import-free.
